Hello Andrea,

I am trying to contact all developers that worked in past on MAME and MESS
drivers, in order to resolve licenses of their files. As you are probably
aware MAME license is not an open source license, and therefore we are not
able to use some other open source project files, we are not able to obtain
some free licenses for commercial software for developers, and not able to
push toward using MAME as platform on Steam or GoG for game license owners
as DosBox did.

My question for you is under which opensource license would you like to put
your file on ?

Currently options are: BSD3, GPL2, LGPL2.

Please note that we try to put devices implementation under BSD3 since more
then one driver use them, but after all it is your decision as license
owner to decide.

Please inform me as soon as possible,

Micko
